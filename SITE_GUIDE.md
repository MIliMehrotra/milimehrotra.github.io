# Maintaining your portfolio

Your website file is `index.html` at the root of this repository.

## Enable GitHub Pages

Open https://github.com/miliuiuc/miliuiuc.github.io/settings/pages and select **Deploy from a branch**, **main**, and **/(root)**, then **Save**.

Once GitHub finishes publishing, visit https://miliuiuc.github.io/ . The first deployment can take up to 10 minutes. Check the Actions tab for deployment errors.

## Update content

Open `index.html`, click the pencil icon, edit the text, and commit your changes. Published GitHub Pages sites update after the new deployment completes.

Project records are in `const projects = [...]` near the bottom of the file. Duplicate a record to add a publication and use a unique `id`. Include the correct title, authors, year, DOI, and supporting source. Supported themes are `Supply chains`, `Healthcare`, and `Social impact`.

## Content notes

This draft presents seven selected publications, not a complete bibliography. Publication summaries are proposed copy for the author's review. Google Scholar blocked automated access, so public Gies and Illinois Experts records were used, with links to the author's Scholar profile. The water-sharing chapter uses 2022 following Illinois Experts; the Gies faculty profile lists 2021. Confirm the preferred year when reviewing.

The illustrations are conceptual, rather than research results. No public availability of code or data is implied.
